# MingoDB App

A web-based application for managing database records with **Create, Read, Update, and Delete (CRUD)** operations, built with **ASP.NET Core MVC** and **MongoDB**.

## Features

- Create new records through input forms
- View a list of saved records and individual record details
- Update existing records
- Delete records
- Validate user input
- Organize application code with the Model-View-Controller pattern

## Tech Stack

- C#
- ASP.NET Core MVC
- MongoDB
- MongoDB.Driver for .NET

## Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) or Docker Engine
- Git
